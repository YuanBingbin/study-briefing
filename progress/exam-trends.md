## 职测变化趋势

| 模块 | 变化 |
|------|------|
| 言语理解 | 阅读量增加，材料题材更广，逻辑填空+片段阅读结合 |
| 数量关系 | 计算量下降，思维难度提升，强调解题技巧 |
| 判断推理 | 图形推理创新题型增多，逻辑判断贴近实际工作场景 |
| 资料分析 | 数据呈现多样化，综合型材料增多，计算精度要求提高 |
| 常识判断 | 时政热点占比提升，浙江本土政策（八八战略、共同富裕）考查增多 |

**新趋势**：数字化改革、智慧政务、千万工程成为命题热门背景

- 应用文格式更灵活：新媒体文案、简报等新形式可能出现
